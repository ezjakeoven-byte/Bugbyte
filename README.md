# Pokémon Heart & Soul — Bugbyte Edition

**Bugbyte Edition** is a personal expansion of Pokémon Heart & Soul, based on H&S v2.0.4.

The goal is to expand the game with additional Pokémon, encounters, quality-of-life features, developer tools, and other gameplay changes while preserving the core Heart & Soul experience.

## Current Version

**Bugbyte Edition v0.2.2**

### Highlights

- BUGBYTE developer mode
- DexNav enabled and integrated
- DexNav support for map-based randomizers
- Guaranteed shiny starters
- Expanded debugging and wild encounter tools
- Custom Gen 1–9 encounter tables
- National Pokédex now granted alongside the regular Pokédex from Oak
- Additional quality-of-life changes
